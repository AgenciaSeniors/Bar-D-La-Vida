# Bar D La Vida - Menu Digital

Menu digital para el **Bar D La Vida** con panel de administracion de productos.

**Sitio:** https://agenciaseniors.github.io/Bar-D-La-Vida/

## Caracteristicas

- Menu visual de bebidas y comidas
- Panel de administracion
- Gestion de productos (agregar, editar, eliminar)
- Diseno responsivo para moviles y escritorio
- GitHub Pages hosting

## Tecnologias

- HTML5 + CSS3
- JavaScript
- GitHub Pages

## Uso

1. Abre el menu: https://agenciaseniors.github.io/Bar-D-La-Vida/
2. Admin: /admin.html
